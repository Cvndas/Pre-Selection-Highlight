# Pre-Selection-Highlight
A highly performant Blender addon that highlights faces, edges, and vertices in edit mode. 

Note: This addon is *fully* vibecoded. I do not have the knowledge surrounding rendering and Blender internals, nor do I have the advanced bpy knowledge that is necessary to write, or contribute, to an addon such as this. This thing was created by asking Claude (the free version) to take the feature from this project https://github.com/5hyuns/maya-workflow-kit-for-blender, and to isolate it into an addon. After this, it took a number of iterations of prompting to make it performant enough to be useful in real projects, as well as to fix some bugs and crashes. 

Since this was created with the free version of Claude, any AI model of similar quality should be able to modify it. Again, I cannot help you with any problems you might have with this addon. 

To install: Download the files, zip them up, and install the zip as an addon within the Blender preferences.
